# StudentHub - Student Dashboard

A colorful, animated student dashboard that gives a quick overview of a student's courses, attendance, assignments and upcoming tasks. The whole project is a single `index.html` file with the HTML, CSS and JavaScript inside it.

## Live Demo

**https://deanu58.github.io/deanu/**

## Features

- Purple sidebar with navigation links and a logout button
- Welcome banner with an **Explore Dashboard** button that scrolls to the stats
- Four summary cards: total courses, attendance, pending assignments and average grade
- Animated count-up numbers on the cards
- **My Courses** panel with animated progress bars for Web Development, Artificial Intelligence and Python Programming
- **Upcoming Tasks** panel with deadlines and a **View All Tasks** button that shows or hides extra tasks
- Pop-up messages for the logout and explore buttons
- Smooth animations and hover effects
- Responsive layout for mobile screens
- Respects the "reduce motion" setting for accessibility

## Built With

- HTML5
- CSS3
- JavaScript
- Poppins font (Google Fonts)
